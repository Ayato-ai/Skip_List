# Skip list (список с пропусками)
**Skip List** — это вероятностная структура данных, которая позволяет эффективно выполнять операции поиска, вставки и удаления элементов в отсортированной последовательности. По сути, это многосвязный список с несколькими уровнями, где каждый верхний уровень служит "экспресс-линией", позволяющей пропускать сразу несколько элементов нижнего уровня и тем самым ускорять операцию поиска.
